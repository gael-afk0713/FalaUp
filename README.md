# FalaUp
Este site foi criado por dois estudantes do Sétimo Ano da Escola Concept de Salvador. Como um projeto de Clubs, nós escolhemos criar um site para ajudar crianças não-verbais com TEA a se comunicarrem. O nosso site é composto por 5 níveis atualmente, cada um tendo 10 cartões de fala, indo de palavras mais básicas até frases um pouco mais complexas. Quando a criança clicar em algum cartão de fala, uma voz falará o que está escrito, que tanto a voz imagem e a palavra pode ser alterada em Configurações.
